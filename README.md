# דשבורד הדריה — הכנסות, הוצאות ורווח

דשבורד סטטי שמושך נתונים חיים משני לוחות מאנדיי ומציג רווח לפי שבוע ולפי חודש.

## איך זה בנוי

אין שלב בנייה ואין תלויות. `index.html` הוא הדשבורד כולו, ו-`api/finance.js`
היא פונקציית serverless יחידה שמדברת עם מאנדיי. וורסל מגיש את הראשון כקובץ
סטטי ומריץ את השנייה לפי דרישה.

| קובץ | תפקיד |
|---|---|
| `index.html` | הדשבורד — סינון, אריחים, תרשימים וטבלה |
| `api/finance.js` | שולף את שני הלוחות ממאנדיי ומחזיר JSON מנורמל |
| `vercel.json` | כתובות נקיות, ומניעת קאשינג על ה-API |

## הרצה

`MONDAY_API_KEY` הוא משתנה הסביבה היחיד. ראה `.env.example`.
בוורסל: Settings → Environment Variables, ואז Redeploy.

## מה הדשבורד לא ממציא

הדשבורד מסמן בעצמו שלושה סוגי בעיות בנתוני המקור, במקום להחליק אותן:

- **תאריכים מרוכזים** — כשרוב ההוצאות נושאות תאריך זהה, הפילוח לשבוע ולחודש
  מאבד משמעות. מוצגת התראה אדומה כל עוד זה המצב.
- **ספירה כפולה** — רשומה ששמה מכיל «קבלה» מתעדת בדרך כלל חשבונית שכבר רשומה.
  היא מנוטרלת כברירת מחדל, וניתן להחזירה במתג.
- **רשומות לבדיקה** — רשומה ששמה מכיל «⚠» או «לבדיקה» מסומנת ומוצגת בנפרד.

ההיגיון הזה יושב ב-`audit()` ב-`index.html` ובשדות `isReceipt` / `needsReview`
ב-`api/finance.js`. ברגע שהנתונים במאנדיי יתוקנו, ההתראות ייעלמו מעצמן.
